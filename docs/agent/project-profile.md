## Identity

- **What**: FlowForge (repo name; site title "Cohort Compass" — naming still open, see
  `docs/10-open-questions.md` Q1) is a public, open-source, static reference site for
  people building with AI agents on consumer subscriptions. It covers concepts, prompting,
  agents/subagents, skills, and tools, organized around how much of a $20/month
  subscription (Claude Pro, ChatGPT Plus) a given task consumes — quota, not API dollars —
  rather than the token-pricing framing most AI reference sites use.
- **Audience**: ~70 people in Pursuit's Native AI Building cohort L1 (mid-program), ~60 in
  L3, plus the general public. Spans complete beginner to advanced builder.
- **Evaluation context**: Portfolio piece. The build process itself (spec-first,
  role-scoped review, phase gates, decision log) is intended to be citable evidence of
  judgment, not just the shipped site.
- **Success looks like**: defined in `docs/00-product-brief.md` — a beginner can pick a
  subscription plan unaided, the quota estimator gets used, field reports accumulate from
  real cohort usage, contributors beyond the founder land merged PRs, no page sits past its
  staleness threshold unaddressed.
- **Deadline / milestones**: none tied to the cohort calendar. Pacing is the M0–M4 plan in
  `docs/08-build-plan.md`.
- **Origin**: new work. M0 (foundation) is complete and merged; M1 (Plans & Usage) has not
  started.

## Constraints

- Data sensitivity: no real user PII by design. Field reports are voluntary, attributed or
  anonymous GitHub issue submissions, human-triaged before merge — see `docs/04`,
  `docs/09`, and `.claude/agents/field-report-triager.md`.
- Breaking-change tolerance: redesign acceptable — this is new work with no external
  consumers yet. Once the site is public, URL structure becomes a stability commitment per
  `docs/01-information-architecture.md`.
- Other constraints: no backend/database/auth ever (`AGENTS.md` golden rule 3); pricing and
  limits data must be human-verified against provider sources, never scraped at build time
  (ADR-003); no benchmark score tables anywhere on the site (`docs/00`).

## Approval gates

Beyond the global defaults in `~/.claude/CLAUDE.md` (architecture, schema/migration,
public contracts, auth, new deps, destructive actions, scope expansion):

- Any change to `plans.yaml` or `models.yaml` values requires the human-verification step
  in `.claude/agents/data-verifier.md` — never an agent auto-merge (ADR-003).
- Making the repository public requires `MAINTAINERS.md` staffed and
  `CODE_OF_CONDUCT.md` contacts filled in first (see Unknowns above).
- Any new content type (beyond the ten in `docs/02-content-types.md`) requires an explicit
  stated reason and a spec update in the same change — the bar is deliberately high.
