# Code of conduct

## The short version

This project exists to help people learn. Most contributors are learning in public, and
some are contributing to an open-source project for the first time. Behave in a way that
makes that easier, not harder.

## Standards

**Expected:**

- Assume good faith. A wrong answer is usually a gap in context, not carelessness.
- Give feedback on the work, not the person.
- Be patient with beginner questions. "How do I open a PR" is a reasonable question here.
- Credit people's contributions.
- Accept that others may reach different conclusions with the same information.

**Not acceptable:**

- Harassment, discriminatory language, or personal attacks
- Sexualized language or imagery, or unwelcome attention of any kind
- Publishing others' private information without permission
- Dismissiveness toward beginners — condescension is the failure mode this project is most
  exposed to, given the audience spans complete beginner to advanced
- Sustained disruption of discussions or review

## Scope

Applies in the repository — issues, pull requests, discussions, commit messages — and in
any space where someone is representing the project.

## Reporting

Report concerns to the maintainers by opening a confidential issue, or by contacting a
maintainer directly.

> **Contacts are not yet assigned.** This is blocked on maintainer staffing — see
> [`MAINTAINERS.md`](MAINTAINERS.md) and `docs/10-open-questions.md` Q3. A code of conduct
> with no named enforcer does not work; fill this in before the repository is made public.

Reports will be handled confidentially. Maintainers who cannot be impartial in a given
report will recuse themselves.

## Enforcement

Depending on severity and pattern:

1. A private clarification of what was out of line
2. A public correction
3. Temporary restriction from participation
4. Permanent removal from the project

Maintainers are held to this document at least as strictly as everyone else.
