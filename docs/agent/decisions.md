## 2026-08-23 — Documentation tier: Standard

**Context**: `/bootstrap-project` run to formalize the meta-workflow for building this
site, after M0 was already complete and merged via ad hoc spec + Codex-implements +
Claude-reviews.
**Options considered**: Lightweight (task brief + final verification only), Standard
(investigation, plan, handoff, verification all recorded), Regulated (full compliance
trail).
**Decision**: Standard. Matches what the project already does in practice (docs/00–11,
per-task PRs), and the confirmed portfolio evaluation context makes the process itself
worth making legible and citable.
**Approved by**: user

## 2026-08-23 — Add the four standard role packets (Argus, Athena, Themis, Apollo)

**Context**: The repo already has five site-content agents in `.claude/agents/`
(page-drafter, content-auditor, data-verifier, field-report-triager, phase-reviewer) that
are dual-purpose build tooling and published site content. These are narrower and
content-specific; they don't cover the general meta-workflow roles (investigate a
question, plan a task, review an implementation, verify it runs).
**Options considered**: (1) add the four standard packets alongside the existing agents,
scoping them so they don't overlap; (2) skip the standard packets and stretch the existing
agents to cover both purposes.
**Decision**: Add all four. `phase-reviewer.md` becomes a Themis-flavored specialization
for milestone boundaries specifically; Themis itself is the general reviewer for anything
narrower than a full milestone.
**Approved by**: user

## 2026-08-23 — Verification depth: unit + runtime/browser

**Context**: The site has interactive components (level toggle now; estimator, decision
trees, task door in later milestones) and a live GitHub Pages deployment.
**Decision**: Verification must include exercising the actual local application (dev
server / build output), not just static schema checks — matching the global default for
UI/runtime work and the project's own `AGENTS.md` definition of done (3 breakpoints, both
themes, keyboard operability).
**Approved by**: user (via approval of the step-5 recommendation)

## 2026-08-23 — Approval gate: data changes never auto-merged

**Context**: `plans.yaml` and `models.yaml` are the most trust-critical files on the site
(ADR-003). A change generated by an agent (even `data-verifier`) carries real credibility
risk if wrong.
**Decision**: Any change to these files' values requires the human-verification step in
`.claude/agents/data-verifier.md` before merge, regardless of how the proposed change was
produced. This is in addition to, not a replacement for, the global approval gates.
**Approved by**: user (via approval of the step-5 recommendation)
