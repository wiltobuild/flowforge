## What they built

I built a small handoff board for recurring client work. Each card captures the current outcome, links to the source material, names the next owner, and records the one decision that could block progress.

## Stack used

I used a browser chat assistant to turn rough notes into consistent handoff briefs, plus another tool for the board itself. Name that tool and explain its role here; the `other` tag requires this plain-language note.

## The prompts and agents behind it

The core prompt asks for an outcome, constraints, evidence links, open decisions, and the smallest next action. Link to the reusable prompt and the handoff template once they are published in the libraries.

## What was harder than expected

The difficult part was not generating a neat summary. It was making uncertainty visible without making every card feel unfinished, so I added an explicit “needs decision” field instead of burying doubts in comments.

## Lessons learned

The board became useful when it reduced the time to restart work, not when it held the most detail. A short, accountable next action and a link to evidence beat a long narrative.
